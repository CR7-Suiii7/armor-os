Executive Summary

A comprehensive security audit, network port hardening, and service reduction was performed on the ARMOR OS workstation. The primary objective was reducing the network-reachable attack surface by eliminating non-essential listening services, disabling multicast information broadcast daemons, and enforcing a strict stateful default-deny firewall rule policy. Following remediation, all unauthorized listening ports were eliminated, leaving TCP Port 22 (SSH) as the sole filtered management entry point. All verification tests achieved PASS status.

3. Firewall Implementation (nftables Default-Deny)

The legacy iptables framework was replaced by native Linux nftables. The configuration enforces stateful connection tracking with default-drop on all inbound frames: 

table inet filter {
    chain input {
        type filter hook input priority filter; policy drop;

        # Connection Tracking: Allow established/related sessions
        ct state established,related accept
        ct state invalid drop

        # Loopback Interface: Allow intra-process IPC
        iifname "lo" accept

        # Rate-Limited ICMP Echo (Max 5/sec to prevent ping floods)
        ip protocol icmp icmp type echo-request limit rate 5/second accept
        ip6 nexthdr icmpv6 icmpv6 type echo-request limit rate 5/second accept

        # Inbound SSH: Explicitly permit TCP 22 with state tracking
        tcp dport 22 ct state new accept

        # Default Deny: Log and drop all other ingress attempts
        log prefix "[ARMOR-DROP-IN]: " flags all counter drop
    }

    chain forward {
        type filter hook forward priority filter; policy drop;
    }

    chain output {
        type filter hook output priority filter; policy accept;
    }
}

5. Security Findings & Analysis

1. Systemd Socket Masking Criticality: Standard service stop commands (systemctl stop avahi-daemon) are inadequate in systemd environments when socket activation units exist. Masking both avahi-daemon.service and avahi-daemon.socket to /dev/null was required to prevent immediate respawning.

2. Inbound Loopback Filtering: Allowing iifname "lo" accept is mandatory for XFCE desktop D-Bus IPC and PipeWire audio. Local port scanning against non-standard ports confirmed unauthorized sockets are immediately rejected.

3. Out-of-Band Remote Access Integrity: The VirtualBox host-to-guest NAT port forwarding rule (127.0.0.1:2222 -> Guest:22) was validated and functions without impediment.

6. Compliance Summary & Recommended Next Steps

Compliance Status: VERIFIED HARDENED

  • Inbound Attack Surface: Minimized strictly to authenticated SSH management.
  • Zero Unwanted Sockets: mDNS, printing, RPC, and Bluetooth services completely disabled and masked.
  • Active Firewall Defense: Stateful default-deny ingress filtering with kernel audit logging.
  • Mandatory Access Control: AppArmor active and enforcing workstation profiles.

Recommended Next Actions

  1. SSH Key-Only Enforcement: Update /etc/ssh/sshd_config to disable password authentication (PasswordAuthentication no) once all administrator Ed25519 public keys are enrolled.
  2. Dynamic Brute-Force Blacklisting: Implement an nftables dynamic set with rate-limiting to automatically ban source IPs exceeding 3 failed SSH authentication attempts within 60 seconds.
  3. Centralized Audit Logging: Configure audispd to stream kernel security events to a remote immutable SIEM over an encrypted TLS channel.
